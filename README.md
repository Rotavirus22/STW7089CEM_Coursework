# Modelling Cloud Server Power Consumption with Polynomial Regression

Coursework for **STW7089CEM Introduction to Statistical Methods for Data Science** (Softwarica College / Coventry University).

The project uses simulated server telemetry to find which of five candidate polynomial regression models best describes total power consumption. It covers exploratory data analysis, least squares model selection with AIC/BIC, train/test validation, and rejection Approximate Bayesian Computation (ABC).

**📄 Full report (PDF): [Rohan_Pokhrel_260537_Assignment_STW7089CEM.pdf](report/Rohan_Pokhrel_260537_Assignment_STW7089CEM.pdf)**

## Data

| File | Contents |
|---|---|
| `data/X.csv` | 4 inputs: `cpu_utilization` (x1), `memory_usage` (x2), `disk_io` (x3), `network_traffic` (x4) |
| `data/y.csv` | Output: `power_consumption` (y) |
| `data/time.csv` | Sampling time in seconds (0 to 999.9 s, step 0.1 s) |

There are 10,000 samples and no missing values.

## How to run

You need R 4.x. Only base R is used, so there are no packages to install.

From the project folder:

```bash
Rscript run_all.R
```

This regenerates every figure in `figures/` and writes the console output to `outputs/console_output.txt`. The 100,000 ABC samples in Task 3 take the longest.

To run one task at a time, open `STW7089CEM_Coursework.Rproj` in RStudio and source the scripts in order. `task3_abc.R` runs `task2_regression.R` itself if its objects are missing. The random seeds are fixed, so the results are reproducible.

## Building the report

The report is LaTeX (`report/main.tex`). It reads the figures from `../figures/` and the R code for the appendix from `../scripts/`, so compile it from inside `report/` with the full repository present:

```bash
cd report
pdflatex main.tex
pdflatex main.tex
```

On Overleaf, upload the whole repository, keeping the folder layout, and set `report/main.tex` as the main document. No BibTeX or Biber run is needed, because the reference list is in `report/sections/references.tex`.
